# Create a group and list my groups

Issue: #14 · Runs on: `mac` · Status: waiting for gate 1

## User story

As a signed-in member, I want to create a group for a trip or a shared flat and see the groups I belong to, so that I have somewhere to record shared expenses.

## Acceptance criteria

### Creating a group (API)

1. Given I am signed in
   When I create a group with a name
   Then the API answers 201 with the group's id, name, member count 1 and creation time, the database holds one membership for it, which is mine, and the group is in my groups
2. Given I am signed in
   When I create a group whose name has spaces before or after it
   Then the group's name is saved without those spaces
3. Given I am signed in
   When I create a group with an empty name, a name of only spaces, or no name
   Then the API answers 400 with `invalid_request` and no group is created
4. Given I already have a group with a name
   When I create another group with the same name
   Then the API creates it, and both groups are in my groups

### Listing my groups (API)

5. Given I belong to some groups
   When I list my groups
   Then I get each group's id, name, member count and creation time, newest first
6. Given I belong to no groups
   When I list my groups
   Then I get an empty list

### One group (API)

7. Given I belong to a group
   When I ask for it by id
   Then I get its id, name, member count and creation time

### Security (API)

8. [security] Given another member's group that I do not belong to
   When I list my groups
   Then that group is not in the list
9. [security] Given a group I do not belong to
   When I ask for it by id
   Then the API answers 404 with `not_found`, the same status and body as for an id no group has
10. [security] Given an id that is not a valid group id
    When I ask for it
    Then the API answers 404 with `not_found`, the same as for an unknown group
11. [security] Given I am not signed in, or my token is wrong or expired
    When I create a group, list my groups or ask for one group
    Then the API answers 401 with `unauthorized` and no group is created
12. [security] Given I am signed in
    When I create a group with a name longer than 100 characters
    Then the API answers 400 with `invalid_request` and no group is created

### Web

13. Given I am signed in on the web and belong to some groups
    When I open the home page
    Then I see "Nhóm của tôi" and each group's name and member count ("1 thành viên"), newest first
14. Given I am signed in on the web and belong to no groups
    When I open the home page
    Then I see "Bạn chưa có nhóm nào."
15. Given I am signed in on the web
    When I enter a name and submit the create form
    Then the new group shows at the top of my groups with "1 thành viên", and the form is empty again
16. Given I am signed in on the web
    When I submit the create form with an empty name or a name of only spaces
    Then I see "Hãy nhập tên nhóm." and no group is created
17. Given I am signed in on the web and the API cannot be reached
    When I open the home page or submit the create form
    Then I see the connection error "Không kết nối được máy chủ. Hãy thử lại." and no group is created

### Mobile

18. Given I am signed in on the app and belong to some groups
    When I open the home screen
    Then I see "Nhóm của tôi" and each group's name and member count, newest first
19. Given I am signed in on the app and belong to no groups
    When I open the home screen
    Then I see "Bạn chưa có nhóm nào."
20. Given I am signed in on the app
    When I enter a name and tap "Tạo nhóm"
    Then the new group shows at the top of my groups with "1 thành viên", and the name field is empty again
21. Given I am signed in on the app
    When I tap "Tạo nhóm" with an empty name or a name of only spaces
    Then I see "Hãy nhập tên nhóm." and no group is created
22. Given I am signed in on the app and the API cannot be reached
    When I open the home screen or tap "Tạo nhóm"
    Then I see the connection error and no group is created

## Assumptions

- A group name is trimmed and must be 1 to 100 characters, with any Unicode (Vietnamese, emoji). One shared schema checks it on web, mobile and the API, so the three can't disagree.
- Names don't have to be unique, even for one member, because two trips can both be called "Đà Lạt".
- A group has no currency field yet: every group is in VND, as `CLAUDE.md` says money is whole VND. A currency field comes with multi-currency.
- A membership is a group and a user, plus when they joined. It has no role, because inviting and removing members is a later issue that can add one.
- The creator's membership is saved together with the group, so a group never exists without a member.
- A group I'm not in, a group that doesn't exist and a malformed id all get the same 404 with `not_found`, so a response never tells me another group exists. `not_found` joins the shared error codes.
- Responses:
  - create: 201 with the group;
  - list: `{ groups: [...] }`, newest first, with no pagination and no limit on how many groups a member has;
  - one group: the group.

  The group is `{ id, name, memberCount, createdAt }`. This is the smallest shape that meets the criteria. "I am its only member" shows as a member count of 1.
- There is no group page on web or mobile. Groups in the list are not links, and getting one group is tested at the API only, because the issue's scope names only a list and a create form for the UI.
- The list and the create form sit on the signed-in home screen, on both web and mobile, under the existing account line.
- While a create is saving, the submit button is disabled, so a double tap doesn't create two groups.
- The name field accepts at most 100 characters. That makes the too-long error an API-only case.
- The UI copy is Vietnamese and lives in the shared package, so tests can check exact strings:
  - heading: "Nhóm của tôi";
  - empty state: "Bạn chưa có nhóm nào.";
  - field label: "Tên nhóm";
  - button: "Tạo nhóm";
  - empty-name error: "Hãy nhập tên nhóm.";
  - member count: "<n> thành viên";
  - connection error: the existing "Không kết nối được máy chủ. Hãy thử lại."
- Creating groups has no rate limit, because only signed-in members can create them and the length cap bounds each request.

## Out of scope

- Inviting, joining or removing members (a later issue)
- Expenses, balances and settlements
- Renaming, archiving or deleting a group
- A group page on web or mobile, and links from the list
- A currency per group
- Pagination or search of my groups
- A rate limit on creating groups
