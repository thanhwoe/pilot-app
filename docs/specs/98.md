# Mobile: open an invite link in the app and join the group

Issue: #98 · Runs on: `mac` · Status: waiting for gate 1

## User story

As someone who got an invite link on my phone, I want it to open the app, so that I can join the group there.

## Acceptance criteria

1. Given the app is installed
   When I open an invite link on the phone
   Then the app opens on the invite, with the group's name and a "join" button

2. Given I am signed in
   When I press "join"
   Then I become a member and the group's screen opens

3. Given I am signed out
   When I open the invite link
   Then the app asks me to sign in and comes back to the invite afterwards

4. [security] Given an invite link with a wrong or malformed token
   When it opens the app
   Then nothing is joined and the app shows the same error as the web

## Assumptions

- The link uses the app's own scheme and the web's path: `gop://invite/<token>`, because the issue says to use the app's scheme and the web already uses `/invite/<token>`.
- "The group's screen" is the groups list with the joined group in it, because the mobile app has no page for one group (the web didn't either in #94).
- A user who is already a member lands on the groups list and nothing changes, the same as on the web (#94, criterion 3).
- "The same error as the web" means the shared `invitesCopy.badLink` text, one message for every link that doesn't work.
- After signing in from an invite, the app returns only to an invite whose token has the right shape (`inviteTokenSchema`); anything else goes to the groups list, as on the web.
- The invite calls go through `guardSession`, and a rejected session ends the session as for other group calls.

## Out of scope

- Sharing the link from the app (the web has it).
- Universal links and app links on a production domain: this uses the app's own scheme until there is one.
- A page for one group.
- Changes to the invite API.
