# Test: hold Server Actions with the shared helper in groups.spec.ts

Issue: #64 · Runs on: `cloud` · Status: waiting for gate 1

## User story

As the developer, I want one way to hold a Server Action open in the web end-to-end tests, so that a fix to how it works is made once, and the next action-form test (#59) doesn't add another copy.

## Acceptance criteria

1. Given `groups.spec.ts`
   When the tests run
   Then `#51 AC 1` and `#54 AC 3, 4` hold the action with `holdFirstServerAction(page, "/")` from `helpers.ts`, and the file has no other copy of the hold code (no `markHeld`, no `holdFirstAction`)

2. Given the change
   When each test's fix is reverted in turn in a scratch branch (`d9f12bc` for #51, `9b169f5` for #54)
   Then `#51 AC 1` fails without the #51 fix and `#54 AC 3, 4` fails without the #54 fix, and the PR shows both failures

3. Given the change
   When `pnpm --filter @gop/web test:e2e --repeat-each=5 e2e/groups.spec.ts` runs
   Then every run passes

## Assumptions

- `holdFirstServerAction` is used as it is: the two copies in `groups.spec.ts` are identical to it, so no change to the helper is needed.
