# Mobile: joining from an invite link opens the group's own screen

Issue: #112 · Runs on: `mac` · Status: waiting for gate 1

## User story

As someone who joined a group from an invite link in the app, I want to land on that group's screen so that I see its expenses and can add one right away.

## Acceptance criteria

1. Given I am signed in and open an invite link for a group I am not in
   When I press "join"
   Then I become a member and the group's own screen opens (its name and expenses), not the groups list

2. Given I am already a member of the group
   When I open its invite link
   Then the group's own screen opens, and nothing about my membership changes

3. [security] Given an invite link with a wrong or malformed token
   When it opens the app
   Then nothing is joined, the same error as today shows, and no group screen opens

## Assumptions

- A member's group id comes from the existing join call, because the invite preview has no group id and the groups list can't be matched to a token. Joining as a member changes nothing, so the issue's scope (no API or shared change) holds.
- If that join call fails for a member, the screen shows the same connection error as today and opens no group screen, because there is no id to go to.
- A join that answers 404 for a member (the link was replaced between the preview and the join) shows the bad-link text, the same as for a new joiner.
