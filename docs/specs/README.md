# Specs

One pair of files per issue:

- `<N>.md`: the spec, written by the `spec` skill and approved at gate 1. It holds the user story, the acceptance criteria in Given/When/Then, the test matrix and what is out of scope.
- `<N>-plan.md`: the plan, approved at gate 2. It lists the files, steps and risks, and tags the work `cloud` or `mac`.
